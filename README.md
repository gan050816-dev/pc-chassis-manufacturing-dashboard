# 电脑机箱智能制造监控看板

## 项目简介

面向电脑机箱制造流程的静态监控看板原型，以冲压、喷涂、组装、质检和包装五个工序为主线，展示生产状态、关键指标和设备下钻信息。

## 主要内容

- 产量、合格率、在制品和 OEE 指标展示。
- 五个工序的状态、节拍与设备参数监控。
- 生产启动/停止、详情弹窗和模拟故障数据。
- 设备工程线稿 SVG 与响应式页面布局。

## 目录结构

```text
index.html          页面入口
css/style.css       页面样式
js/app.js           模拟数据与交互逻辑
images/             五个工序的 SVG 设备图
PROJECT_REPORT.md   架构与设计说明
```

## 环境依赖

直接打开 `index.html`，或在当前目录启动任意静态文件服务器。
